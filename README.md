# AI Assistant - Multi-Model Consensus

A single-page web app that sends one question to several AI models and combines their answers into a consensus response. The interface is in Turkish.

## Features

- Queries multiple AI models and compares their answers
- Presents a consensus-style combined response
- Runs entirely in the browser from a single HTML file

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Higer23/ai.git
   cd ai
   ```
2. Open `index.html` in a modern browser.

If the app calls external AI APIs, you need to supply your own API keys. Do not commit keys to the repository; keep them out of source control.
